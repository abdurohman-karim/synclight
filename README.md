# synclight

Лёгкая замена приложения SyncLight для подсветки монитора лентами Robobloq, написанная на Rust.
Захват экрана через DXGI, уменьшение кадра на видеокарте, отправка цветов на ленту по USB HID.

> Неофициальный проект. Не связан с Robobloq; протокол ленты восстановлен для совместимости
> с собственным оборудованием.

|                              | SyncLight 2.18 (Electron) | synclight (Rust)                    |
|------------------------------|---------------------------|-------------------------------------|
| Процессы в фоне              | 5                         | 1                                   |
| Память в фоне                | ~374 МБ                   | ~40 МБ                              |
| Процессор при синхронизации  | ~34% одного ядра          | ~4–6% одного ядра                   |
| На диске                     | 250 МБ                    | ~4 МБ                               |
| Захват экрана                | GDI `BitBlt` на CPU       | DXGI Desktop Duplication + GPU mips |

Замеры сделаны на одной машине (4K-монитор, RTX 3070, лента на 65 светодиодов), но не одновременно.

## Программы

- `synclight-tray.exe` — фоновая служба с иконкой в трее.
  Клик по иконке открывает окно настроек, правый клик — короткое меню (открыть, вкл/выкл, выход).
  - `synclight-tray.exe --ui` — окно настроек (отдельный процесс, живёт, только пока окно открыто);
  - `synclight-tray.exe --autostart on|off` — включить/выключить автозапуск.
- `synclight-rs.exe` — консольная утилита для диагностики: `--info`, `--test`, `--test-leds`,
  `--dry-run`, `--per-led`, `--help`.

## Режимы

Те же, что в оригинальном SyncLight, переключаются плитками в окне (`mode` в `config.ini`):

| Режим | Что делает | Что уходит на ленту |
|---|---|---|
| **Экран** (`sync`) | цвета по краям экрана; пресеты «Игры» / «Фильмы» (Game/Movie mode) | кадры `SC … 0x80` |
| **Цвет** (`static`) | один цвет: радужная полоса и готовые образцы | `RB … 0x86 [1 r g b N]` |
| **Эффекты** (`effect`) | 7 встроенных анимаций прошивки (Dynamic) + скорость | `RB … 0x85 02 i`, `RB … 0x8A speed` |
| **Музыка** (`rhythm`) | 7 эффектов под звук (Rhythm): от звука компьютера или от микрофона ленты | компьютер: `RB … 0x98 i level` 25 раз/с; микрофон: `RB … 0x85 03 i`, `RB … 0x8B sens` |

- «Звук компьютера» — пиковый уровень звука Windows (`IAudioMeterInformation`), как в оригинале;
  ничего не записывается. Нужна прошивка ≥ 1.8.2.
- «Яркость ленты» — аппаратная яркость самой ленты (`RB … 0x87 5..255`), действует во всех режимах.
- В режимах без экрана захват экрана выключается полностью.
- При первом запуске цвет, яркость ленты, скорость эффектов и чувствительность берутся из настроек SyncLight.

## Окно настроек

- живой предпросмотр: монитор и все светодиоды вокруг него теми цветами, что сейчас на ленте
  (в режиме «Музыка» — громкость); при наведении — номер и цвет светодиода;
- плитки режимов и настройки выбранного режима;
- режим зон, яркость, плавность, частота обновления, насыщенные цвета;
- установка ленты: где она начинается и сколько сторон занимает;
- автозапуск, журнал, файл настроек; статус службы и замеры (кадры экрана, отправки на ленту, USB, видеокарта).

Все изменения применяются сразу. Окно пишет `config.ini` и отправляет фоновой службе
сообщение `WM_APP+2`; живые цвета и статус читает из общей памяти `Local\synclight-rs-status`.

## Два режима зон

| | Сетка 16x9 (`per_led = 0`) | Зона на светодиод (`per_led = 1`) |
|---|---|---|
| Зон для ленты 65 LED | 34 (по 1–2 светодиода) | 65 |
| Кадр на ленту | до 177 байт, 3 USB-пакета | до 332 байт, 6 USB-пакетов |
| USB на кадр (замер на видео) | ~1,6–3,2 мс | ~3,8–5,8 мс |

Соседние светодиоды с одинаковым цветом склеиваются в один сегмент, поэтому реальный кадр обычно меньше.

## Как устроено

- **Захват** (`src/capture.rs`): DXGI Desktop Duplication → `GenerateMips` на видеокарте →
  чтение маленькой копии (240x135 для 4K) через кольцо из 3 буферов. Ожидание видеокарты — по
  `ID3D11Fence` с ограничением ~2 мс; если видеокарта занята, кадр забирается на следующем шаге.
  Неподвижный экран не стоит ничего: `AcquireNextFrame` просто ждёт.
- **Движок** (`src/engine.rs`): зоны → экспоненциальное сглаживание → яркость/насыщенность →
  ограничение мощности (R+G+B ≤ 255, лента питается от USB). Сам переподключает ленту,
  гасит её на экране блокировки и уступает ленту оригинальному SyncLight, если тот запущен.
- **Отправка** (`src/sender.rs`): отдельный поток; при отставании ленты старый кадр заменяется новым.
- **Протокол** (`src/device.rs`): HID `1A86:FE07`, интерфейс 0; пакеты по 64 байта.
  - запрос информации: `"RB" len id 0x82 sum`;
  - кадр синхронизации: `"SC" len16be id 0x80 [start r g b end]… sum`;
  - цвет участков: `"RB" len id 0x86 [start r g b end]… sum`;
  - эффект: `"RB" len id 0x85 group index sum` (group 2 — Dynamic, 3 — Rhythm);
  - яркость / скорость / чувствительность: `"RB" len id 0x87|0x8A|0x8B value sum`;
  - шаг ритма от компьютера: `"RB" len id 0x98 index level sum`;
  - выключение: `"RB" len id 0x97 sum`.
- **Звук** (`src/audio.rs`): пиковый уровень устройства вывода по умолчанию.

## Сборка и установка

Нужны Rust (stable, MSVC) и Windows 10/11.

```powershell
cargo build --release
taskkill /IM synclight-tray.exe
New-Item -ItemType Directory -Force "$env:LOCALAPPDATA\Programs\synclight-rs" | Out-Null
Copy-Item target\release\synclight-tray.exe, target\release\synclight-rs.exe "$env:LOCALAPPDATA\Programs\synclight-rs\" -Force
& "$env:LOCALAPPDATA\Programs\synclight-rs\synclight-tray.exe" --autostart on
Start-Process "$env:LOCALAPPDATA\Programs\synclight-rs\synclight-tray.exe"
```

Перед первым запуском закройте оригинальный SyncLight: пока он работает, synclight стоит на паузе.
